
# IBM HR Analytics - Employee Attrition Analysis

This project performs exploratory data analysis and feature engineering on the IBM HR Analytics Employee Attrition & Performance dataset.

## Tasks Performed

- Data cleaning
- Missing value analysis
- Duplicate detection
- Outlier analysis
- Exploratory Data Analysis
- Attrition distribution analysis
- Correlation analysis
- Employee group comparisons
- Feature engineering

## Visualizations

- Attrition distribution
- Age distribution by attrition
- Monthly income vs attrition
- Correlation heatmap
- Overtime vs attrition
- Job role vs attrition

## Engineered Features

- OverallSatisfaction
- CompanyTenureRatio
- IncomePerExperienceYear
- PromotionGapRatio
- EarlyCareerEmployee

## Dataset

IBM HR Analytics Employee Attrition & Performance dataset from Kaggle.
